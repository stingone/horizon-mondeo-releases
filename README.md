# Horizon Nav — Mondeo-releases

Alleen kant-en-klare APK's van een eigen Horizon Nav-versie voor één specifieke head unit. De broncode staat in een privé repository.
Gebaseerd op [Horizon-Maps](https://github.com/benbishop028-arch/Horizon-Maps) (GPL-3.0).

Deze APK's zijn niet bedoeld voor andere toestellen.

De release met tag `app` bevat steeds de nieuwste versie: de APK, het `.sha256`-controlegetal en `version.json`.
Horizons eigen update-functie leest die release.
